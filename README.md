# ALLGAMES

Личный репозиторий игровых проектов и прототипов [SanchukS](https://github.com/SanchukS).

## Текущий проект

Мобильная RPG, вдохновлённая **Butcher Hero**, с акцентом на развитие персонажа и разнообразие билдов.

Основная идея — создать глубокое дерево талантов и необычную экипировку, которые меняют поведение способностей, тактику боя и стиль игры. Игрок должен получать удовольствие от поиска и проверки новых сочетаний.

Планируемые особенности:

- Короткие игровые сессии и управление, удобное на телефоне.
- Дерево талантов с выбором разных направлений развития.
- Уникальные предметы с эффектами, заметно меняющими геймплей.
- Взаимодействия между талантами, экипировкой и способностями.
- Сражения с обычными врагами и боссами для проверки билдов.

## Оружие и уровни

Доступны меч, кинжал и молот. Обычный удар выбирает ближайшего врага в прицеле, способности с уроном по площади — всех в области. Урон оружия считается в процентах от урона персонажа, сопротивления типам урона для этих оружий отключены.

| Оружие | Урон | Ударов/с | Область |
| --- | --- | --- | --- |
| Меч | 100% | 1 | Сектор 140°, 2,3 м |
| Кинжал | 60% | 2 | Сектор 80°, 1,5 м |
| Молот | 180% | 0,65 | Круг 1,43 м |

В инвентаре нажмите оружие: карточка показывает пять уровней. Кнопки **− уровень / + уровень** меняют уровень от 1 до 5. На уровнях 2 и 4 открываются способности, на 3 и 5 — улучшения. Уровень 5 позволяет пробудить оружие; конкретные синергии ещё не определены. Прокачка сохраняется, копии оружия больше не повышают уровень автоматически.

- **Меч:** быстрая дуга джойстиком 90° за последние 650 мс перед отпусканием даёт разрез по площади; обратная дуга на уровне 3 даёт второй разрез. Уровень 4 открывает парирование атакующего врага, уровень 5 — общий запас защиты в два урона персонажа для нескольких задетых атакующих врагов.
- **Кинжал:** стаки на каждой цели повышают урон. Каждый десятый стак даёт дополнительный урон, зависящим от числа десятков стаков.
- **Молот:** удержание заряжает площадь и урон до ×2. Жест назад-вперёд относительно последнего движения включает выбор точки прыжка. Оба приёма отбрасывают и оглушают на секунду.

Жёлтый кружок над героем — первая способность, красный — вторая. Число в потемневшем кружке показывает оставшиеся обычные попадания до восстановления. Специальные удары, промахи и удары по декорациям его не уменьшают. Подробности временных настроек и проверок: [weapon-mechanics.md](docs/weapon-mechanics.md).

## Играть в браузере

[Открыть игру](https://sanchuks.github.io/ALLGAMES/) — игра запускается прямо на странице, в том числе на телефоне.

GitHub Actions автоматически проверяет, собирает и публикует игру после изменений `games/allgames` в `main`. Workflow: [pages.yml](.github/workflows/pages.yml). Можно также запустить публикацию вручную: Actions → Publish game to GitHub Pages → Run workflow. Публикуется содержимое `games/allgames/dist`; путь `/ALLGAMES/` задаётся только для сборки сайта, локальная разработка работает как раньше.

## Локальный запуск

Нужны Node.js 22+ и pnpm. Для воспроизводимой установки используйте `pnpm-lock.yaml`.

```bash
cd games/allgames
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

Откройте http://127.0.0.1:5173/ в браузере. Движение — WASD, стрелки или перетаскивание мышью/пальцем слева. Для атаки потяните красный джойстик справа: появится сектор удара. Отпустите, чтобы ударить; верните в центр, чтобы отменить обычную атаку (заряженный молот ударит и при отпускании в центре). Оранжевый сектор означает перезарядку; отпускание в этот момент не ставит удар в очередь. Автоатака отключена во вступлении и основной игре.

```bash
pnpm test                        # управление атакой и геометрия прицела
pnpm build                       # проверка TypeScript и production-сборка
pnpm sim --runs 3 --until 5       # короткая проверка симулятора баланса
```

Служебные страницы: `/viewer.html` (модели), `/roster.html` (персонажи), `/balance.html` (симулятор баланса).

Ближайшие шаги:

1. Изучить исходники прототипа и определить, какие системы можно использовать.
2. Подготовить небольшую игровую сцену для проверки боя.
3. Реализовать несколько заметно различающихся билдов через таланты и предметы.
4. Проверить управление и производительность на телефоне.
